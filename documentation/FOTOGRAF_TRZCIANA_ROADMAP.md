# Fotograf Trzciana — roadmapa uzupełniania treści

Ten dokument jest bazą kolejnych prac nad treściami strony Fotograf Trzciana / WAVE Studio.

## Zasada pracy

Podstrony uzupełniamy pojedynczo. Każda strona powinna otrzymać treść dla klienta, odpowiednie grafiki, wyraźne CTA, SEO oraz kontrolę wersji mobilnej.

Standardowa checklista każdej strony:

- [ ] tekst napisany językiem klienta;
- [ ] jasny nagłówek i korzyść dla klienta;
- [ ] zdjęcie główne lub grafika;
- [ ] teksty alternatywne zdjęć;
- [ ] sekcja „jak to działa” lub „co otrzymasz”;
- [ ] aktualna cena z centralnego cennika albo informacja o wycenie indywidualnej;
- [ ] przycisk telefonu, WhatsAppa lub kontaktu;
- [ ] FAQ;
- [ ] linki do powiązanych usług;
- [ ] title SEO;
- [ ] meta description;
- [ ] poprawne linki i brak błędów kodowania;
- [ ] kontrola wersji mobilnej.

## Ważne założenia techniczne

- Ceny wyświetlamy przez centralny cennik i klucze cenowe.
- Nie tworzymy duplikatów stron bez sprawdzenia panelu administracyjnego.
- Wymagania dokumentów należy przedstawiać jako aktualne na podstawie informacji instytucji, bez gwarantowania decyzji urzędu.
- Przed publikacją każdej strony trzeba usunąć błędne znaki kodowania (`?`, `Â`, `Ĺ` itd.).
- Publikacja zdjęć klientów wymaga osobnej zgody.
- Formularze, rezerwacje, zamówienia i płatności opisujemy zgodnie z rzeczywistym działaniem aplikacji.
- Nie publikujemy automatycznie żadnej strony bez osobnego potwierdzenia.
